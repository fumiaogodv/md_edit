# Markdown 阅读器 —— 项目大纲

> 一个本地 Markdown 阅读器，支持文件夹分类导航、标题大纲跳转、全文搜索、轻量编辑，最终以 Docker 镜像形式交付，跨设备运行。

---

## 一、项目定位与目标

构建一个 **Web 前后端分离** 的 Markdown 阅读器，核心解决「大量 md 文件按目录分类管理 + 快速阅读 + 标题跳转 + 内容搜索」的问题。

**交付形态**：Docker 镜像。用户在任意设备上 `docker run` 挂载本地目录即可使用，无需安装 Node/Python 环境。

## 三、技术选型

| 层 | 技术 | 理由 |
|----|------|------|
| 后端 | Python 3.11 + FastAPI | 现代、自动 API 文档、性能好、运行方便 |
| 服务器 | Uvicorn | 生产级 ASGI 服务器 |
| 前端 | Vue 3 + Vite | 展示风格优秀，生态成熟 |
| UI 组件 | Naive UI | 现代美观，暗色主题友好 |
| Markdown 渲染 | markdown-it + 插件 | 表格/锚点/公式插件齐全 |
| 代码高亮 | highlight.js | 主题丰富 |
| 数学公式 | KaTeX | 快速、轻量 |
| 编辑器 | CodeMirror 6 | 适合轻量编辑，支持 md 语法高亮 |
| 搜索 | 后端扫描 + 前端高亮 | 轻量，无需引入 ES 等重组件 |
| 交付 | Docker（多阶段构建） | 跨设备、环境隔离 |

## 四、架构设计

```
┌─────────────────────────────────────────────────────┐
│                    浏览器 (前端)                        │
│  ┌─────────┬───────────────────┬─────────────────┐  │
│  │ 文件树    │    Markdown 渲染区  │   标题大纲        │  │
│  │ (分类导航) │   (阅读/编辑切换)    │  (一二级标题跳转)  │  │
│  └─────────┴───────────────────┴─────────────────┘  │
│                    ┌────────────────┐                │
│                    │  搜索栏(全文)    │                │
│                    └────────────────┘                │
└──────────────────────────┬──────────────────────────┘
                           │ HTTP API (JSON)
┌──────────────────────────▼──────────────────────────┐
│                后端服务 (FastAPI + Uvicorn)            │
│  /api/tree  /api/file  /api/search  /api/static      │
│                    ┌────────────────┐                │
│                    │ 静态文件服务(前端) │                │
│                    └────────────────┘                │
└──────────────────────────┬──────────────────────────┘
                           │ 读取/写入磁盘
┌──────────────────────────▼──────────────────────────┐
│             挂载目录 (Docker volume)                    │
│              /data  ← 宿主机某个目录                     │
│              ├── 操作系统/                              │
│              ├── 网络/                                 │
│              └── 数据库/                               │
└─────────────────────────────────────────────────────┘
```

**核心设计原则**：
- 后端只允许访问挂载根目录 `/data` 内部，路径穿越被严格拦截
- 前端拿到的永远是**相对路径**，只能通过 `/api/...` 接口访问
- Docker 语义：`docker run -v D:/notes:/data`，容器内只见 `/data`

## 六、后端 API 设计

统一前缀 `/api`，返回 JSON。

| 方法 | 路径 | 功能 | 参数 |
|------|------|------|------|
| GET | `/api/tree` | 获取目录树（根级） | 无 |
| GET | `/api/tree/{path}` | 获取某文件夹子项（懒加载） | path: 相对路径 |
| GET | `/api/file/{path}` | 读取文件内容 | path: 相对路径 |
| PUT | `/api/file/{path}` | 保存文件内容 | body: {content} |
| GET | `/api/search?q=xx` | 全文搜索 | q: 关键字 |

### 目录树节点结构

```json
{
  "name": "进程调度.md",
  "type": "file",              // "dir" | "file"
  "path": "操作系统/进程调度.md", // 相对路径
  "size": 2048,                // 字节（可选）
  "ext": "md"                  // 扩展名（用于图标）
}
```

- `type=dir` 的节点含 `children` 数组；懒加载时首次只返回一层
- 后端扫描过滤隐藏文件（`.` 开头）

### 全文搜索返回结构

```json
{
  "query": "调度",
  "results": [
    {
      "path": "操作系统/进程调度.md",
      "name": "进程调度.md",
      "matches": [
        { "line": 12, "text": "进程调度的基本概念..." }
      ]
    }
  ]
}
```

搜索策略：遍历挂载目录下所有 `.md` 文件，逐文件读取内容按行匹配关键字，返回命中行（限制每文件匹配行数，避免结果爆炸）。

## 七、前端模块设计

### 1. 三栏主布局（Reader.vue）

```
┌──────────────┬────────────────────────┬──────────────┐
│  FileTree     │  MarkdownView/Editor    │  Outline     │
│  (左侧,可收起) │  (中间,自适应)           │  (右侧,可收起) │
└──────────────┴────────────────────────┴──────────────┘
顶部：工具栏（搜索框、编辑/预览切换、收起侧栏按钮）
```

### 2. 文件树（FileTree.vue）
- 递归组件渲染，文件夹可展开/折叠
- 懒加载：点击文件夹时才请求子项
- 图标区分：📁 文件夹、📄 md 文件、其他文件用扩展名对应图标
- 点击 md 文件 → 加载并渲染；点击非 md 文件 → 提示「不支持预览」

### 3. Markdown 渲染（MarkdownView.vue）
- markdown-it 渲染，配置插件：
  - 表格（GFM，内置）
  - `markdown-it-anchor`：标题锚点
  - `markdown-it-katex`：数学公式
  - `markdown-it-task-lists`：任务列表
- highlight.js 代码高亮
- 自定义 md 样式（GitHub 风格，适配暗色主题）

### 4. 标题大纲（Outline.vue）
- 渲染后从 DOM 提取 `h1`、`h2`（**只展示这两级**）
- 缩进区分层级，点击 `scrollIntoView({ behavior: 'smooth' })`
- 滚动时高亮当前章节（IntersectionObserver 实现，可选）

### 5. 编辑器（MarkdownEditor.vue）
- CodeMirror 6，md 语法高亮
- 阅读模式 → 点「编辑」→ 编辑模式 → 点「保存」→ PUT 写回 → 回到阅读模式
- 保存成功/失败有提示

### 6. 搜索（SearchBar.vue）
- 输入关键字 → 调 `/api/search` → 展示结果列表
- 点击结果 → 打开对应文件并定位到命中行（高亮）

## 八、Docker 打包方案

### 多阶段构建（Dockerfile）

```dockerfile
# 阶段1：构建前端
FROM node:20-alpine AS webbuild
WORKDIR /app/web
COPY web/package*.json ./
RUN npm install
COPY web/ ./
RUN npm run build

# 阶段2：运行后端 + 托管前端产物
FROM python:3.11-slim
WORKDIR /app
COPY server/requirements.txt ./
RUN pip install --no-cache-dir -r requirements.txt
COPY server/ ./server/
COPY --from=webbuild /app/web/dist ./static   # 前端产物
ENV ROOT_DIR=/data PORT=8000
EXPOSE 8000
CMD ["uvicorn", "server.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

### 运行方式

```bash
# 构建镜像
docker build -t md-reader .

# 运行（把本机 D:/notes 挂载到容器 /data）
docker run -d -p 8000:8000 -v D:/notes:/data --name md-reader md-reader

# 浏览器访问
# http://localhost:8000
```

### 关键点
- 前端构建产物由后端 **FastAPI 静态托管**，单一镜像、单端口，部署最简单
- 挂载目录通过环境变量 `ROOT_DIR` 指定（默认 `/data`）
- 跨设备：只要有 Docker，任何机器 `docker run` 即用

## 十、风险与注意事项

1. **路径安全**：严格校验相对路径，禁止 `../` 穿越，防止越权读取容器内其他文件
2. **大目录性能**：懒加载 + 搜索结果行数限制，避免卡顿
3. **编码问题**：读取文件统一用 UTF-8，异常编码降级处理
4. **并发写入**：同一文件多端同时编辑存在覆盖风险（轻量场景可接受，后续可加文件锁）
5. **KaTeX 体积**：公式若不用，可后续按需裁剪，不影响主流程
