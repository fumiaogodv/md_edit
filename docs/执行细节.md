## 一、后端实现细节

### 1.1 配置文件（config.py）

```python
import os

ROOT_DIR = os.environ.get("ROOT_DIR", "/data")   # 挂载根目录
PORT = int(os.environ.get("PORT", "8000"))
HOST = "0.0.0.0"

# 允许预览/编辑的文件扩展名（只有 md 可编辑）
EDITABLE_EXTS = {".md", ".markdown", ".txt"}
# 搜索时扫描的扩展名
SEARCHABLE_EXTS = {".md", ".markdown", ".txt"}
# 隐藏文件/目录（跳过）
IGNORE_PREFIXES = (".",)
```

### 1.2 路径安全校验（关键！）

所有相对路径进入后端后，必须做归一化校验，防止 `../` 穿越：

```python
from pathlib import Path

def safe_resolve(relative_path: str) -> Path:
    """把相对路径安全解析到 ROOT_DIR 内部，越界则抛错。"""
    root = Path(ROOT_DIR).resolve()
    target = (root / relative_path).resolve()
    # 必须是 root 的子路径
    if root != target and root not in target.parents:
        raise ValueError("非法路径")
    return target
```

> 踩坑：直接用字符串拼接 `ROOT_DIR + path` 会暴露穿越漏洞。必须 `resolve()` 后判断父子关系。

### 1.3 目录树扫描（service/tree.py）

```python
def list_dir(relative_path: str = "") -> list[dict]:
    """返回某目录下的直接子项（懒加载，不递归）。"""
    target = safe_resolve(relative_path)
    items = []
    for p in sorted(target.iterdir(), key=lambda x: (x.is_file(), x.name.lower())):
        if p.name.startswith(IGNORE_PREFIXES):
            continue
        items.append({
            "name": p.name,
            "type": "dir" if p.is_dir() else "file",
            "path": str(p.relative_to(Path(ROOT_DIR))).replace("\\", "/"),
            "ext": p.suffix.lower() if p.is_file() else "",
            "size": p.stat().st_size if p.is_file() else 0,
        })
    return items
```

细节：
- **排序**：文件夹在前、文件在后，均按名称（忽略大小写）排序
- **路径统一正斜杠** `/`，避免 Windows/容器混用问题
- 懒加载：`GET /api/tree` 返回根层，`GET /api/tree/{path}` 返回子层

### 1.4 文件读写（service/file.py）

```python
def read_file(relative_path: str) -> str:
    target = safe_resolve(relative_path)
    if not target.is_file():
        raise FileNotFoundError
    # 优先 UTF-8，失败降级 GBK（兼容中文老文件）
    for enc in ("utf-8", "gbk", "utf-8-sig"):
        try:
            return target.read_text(encoding=enc)
        except UnicodeDecodeError:
            continue
    raise UnicodeDecodeError

def write_file(relative_path: str, content: str) -> None:
    target = safe_resolve(relative_path)
    if target.suffix.lower() not in EDITABLE_EXTS:
        raise PermissionError("该文件类型不支持编辑")
    target.write_text(content, encoding="utf-8")
```

> 踩坑：中文 Windows 下部分老 md 是 GBK 编码，直接 `utf-8` 读取会报错，需多编码降级。

### 1.5 全文搜索（service/search.py）

```python
def search(keyword: str, limit_per_file: int = 10) -> list[dict]:
    results = []
    root = Path(ROOT_DIR)
    for p in root.rglob("*"):
        if p.is_dir() or p.suffix.lower() not in SEARCHABLE_EXTS:
            continue
        if p.name.startswith(IGNORE_PREFIXES):
            continue
        matches = []
        try:
            text = p.read_text(encoding="utf-8")
        except (UnicodeDecodeError, OSError):
            continue
        for i, line in enumerate(text.splitlines(), 1):
            if keyword in line:
                matches.append({"line": i, "text": line.strip()[:200]})
                if len(matches) >= limit_per_file:
                    break
        if matches:
            results.append({
                "path": str(p.relative_to(root)).replace("\\", "/"),
                "name": p.name,
                "matches": matches,
            })
    return results
```

细节：
- `rglob("*")` 递归遍历，只扫文本类扩展名
- 每文件命中行数上限 10，防止超长文件撑爆结果
- 关键字**区分大小写**（可配置忽略大小写，后续加）
- 大目录场景下，这是 O(文件数×文件大小)，对纯文本足够快；若未来文件量级到数万可再引入索引

### 1.6 FastAPI 路由（main.py）

```python
from fastapi import FastAPI, HTTPException
from fastapi.staticfiles import StaticFiles

app = FastAPI(title="MD Reader")

@app.get("/api/tree")
@app.get("/api/tree/{path:path}")
def tree(path: str = ""):
    try:
        return list_dir(path)
    except ValueError as e:
        raise HTTPException(400, str(e))

@app.get("/api/file/{path:path}")
def get_file(path: str):
    try:
        return {"path": path, "content": read_file(path)}
    except FileNotFoundError:
        raise HTTPException(404, "文件不存在")

@app.put("/api/file/{path:path}")
def put_file(path: str, body: dict):
    try:
        write_file(path, body["content"])
        return {"ok": True}
    except PermissionError as e:
        raise HTTPException(403, str(e))

@app.get("/api/search")
def search(q: str):
    return search(q)

# 前端静态托管（挂在最后，避免吞掉 /api）
app.mount("/", StaticFiles(directory="static", html=True), name="static")
```

> 注意：`{path:path}` 支持带 `/` 的完整相对路径；静态托管必须 `html=True` 并放在所有 API 之后，否则 `/api` 会被静态中间件拦截。

### 2.2 Markdown 渲染配置（MarkdownView.vue 核心）

```js
import MarkdownIt from 'markdown-it'
import anchor from 'markdown-it-anchor'
import katex from 'markdown-it-katex'
import taskLists from 'markdown-it-task-lists'
import hljs from 'highlight.js'

const md = new MarkdownIt({
  html: true,          // 允许内嵌 HTML
  linkify: true,       // 自动识别链接
  highlight(code, lang) {
    if (lang && hljs.getLanguage(lang)) {
      return hljs.highlight(code, { language: lang }).value
    }
    return hljs.highlightAuto(code).value
  }
})
  .use(anchor, { slugify: s => s, level: [1, 2, 3, 4, 5, 6] })
  .use(katex)
  .use(taskLists)
```

细节：
- `slugify: s => s` 直接用中文标题做 id，简单可靠（markdown-it 会处理重复加 `-1`）
- `level: [1..6]` 给所有标题加锚点，但**大纲只取 h1/h2**
- highlight.js 主题在全局 CSS 引入（暗色推荐 `github-dark`）

### 2.3 标题大纲提取（Outline.vue）

```js
// 渲染后从容器 DOM 提取 h1/h2
function extractOutline(el) {
  const outline = []
  el.querySelectorAll('h1, h2').forEach(h => {
    outline.push({
      level: h.tagName === 'H1' ? 1 : 2,
      text: h.textContent,
      id: h.id,
    })
  })
  return outline
}

function jumpTo(id) {
  document.getElementById(id)?.scrollIntoView({ behavior: 'smooth', block: 'start' })
}
```

- **只保留 `h1`、`h2`**（符合需求）
- 大纲显示层级缩进，点击平滑滚动
- （可选进阶）用 IntersectionObserver 在滚动时高亮当前章节

## 五、边界情况清单（开发时逐条验证）

- [ ] 空目录：文件树显示「暂无文件」
- [ ] 文件名含中文/空格/特殊字符：路径 URL 编码正确
- [ ] 超长 md 文件：渲染不卡（可加渲染节流）
- [ ] 非 md 文件点击：友好提示不可预览
- [ ] GBK 编码老文件：正常读取不报错
- [ ] 搜索无结果：显示「未找到相关文件」
- [ ] 保存失败（只读目录）：给出明确错误提示
- [ ] 浏览器刷新：记住当前打开的文件（URL hash 存 path）
- [ ] 公式/代码块/表格混排：渲染正确不串
- [ ] 目录树超深层级：递归渲染无栈溢出
