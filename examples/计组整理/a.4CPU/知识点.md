# CPU · 知识点

## 一、CPU 的四部分组成

**1. 执行部件**
- 算术逻辑单元（ALU）
- 标志寄存器（FR）

**2. 寄存器**
- 指令寄存器（IR），不可见
- 程序计数器（PC）
- 通用寄存器组（GPRs）
- 存储器地址寄存器（MAR），不可见
- 存储器数据寄存器（MDR），不可见
- 页表基址寄存器，不可见

**3. 控制部件（CU）**
- 指令译码器（ID）
- 时序系统
- 微操作信号发生器
- 总线控制逻辑

**4. 中断系统**

## 二、各个周期的划分

**计算机底层**
- 1 除以时钟频率 = 时钟周期（也叫脉冲、节拍）
- 机器周期 = 时钟周期 × 节拍数

**硬布线**
- 若干微操作 = 节拍
- 若干节拍 = 工作周期（机器周期）
- 若干工作周期 = 指令

**微程序**
- 若干微操作 = 微指令
- 微程序 = 指令

## 三、控制器的零散结论

1.CPU = 数据通路（Datapath）+ 控制部件（Control Unit）。

2.硬布线控制器的缺点：设计复杂，扩充新指令很难。优点：纯电路实现，速度十分快。

3.微程序的思想：本来四个周期完成一条指令，若干指令完成一个程序，继续嵌套下去。把每个周期分为若干微指令，每一个微指令包含若干微操作（微命令），类似一种封装的思想。

4.内部结构上，微程序控制器类似于「CPU 的 CPU」。

5.广义上一条指令对应一个微程序；这里的微程序段，n 条机器指令就对应 n+1 个微程序段。

6.执行周期的平均长度是四条微指令。

7.微指令 = 某一个周期（取值周期、执行周期）；微命令 = 微操作。

8.控制部分向执行部件发出的控制信号称为微命令，微命令执行的操作称为微操作。

9.定长的机器周期，选需要的节拍数最大者为准。

10.对于实际节拍数少于机器周期的微操作，安排在末尾。

11.下地址指的是这个微指令完成后要执行的地址。不同指令不一定都要「取值后间址」，比如某条指令结束时不需要间址，那就通过标志位的信息进行跳转。包括执行周期结束后可能进入中断周期，这时候也需要跳转。

## 四、流水线的零散结论

12.Cache 分为指令 Cache 和 data Cache，分别用于存放数据和指令，让访存这个周期的时间变短。

13.译码（decode）都是从寄存器访问数据，而不是从主存访问，即使数据不在，也是先把数据放入寄存器。

14.为了方便管理和安排，把耗时最长的那个阶段需要的时间，作为指令流水线的机器周期。

15.为了保证数据不丢失，每一个功能段后面都有一个缓冲区，用于暂时存放数据。

16.流水线寄存器是硬件不动的，是指令在移动，才造成了流水线的局面。

17.在有转发（旁路）技术的前提下：
- 运算类到运算类（ALU → ALU）：需要插入 0 条空操作，完全无气泡。
- 读内存类到运算类（Load → Use）：因为必须等 MEM 访存结束，必定需要插入 1 条空操作，即 1 个周期的气泡或阻塞。

18.对于常规单流水线（度为1），执行 n 条指令的时间为：T = [ k + (n - 1) ] × Δt，其中 k 为流水段数，Δt 为每个流水段耗时。

19.当采用度为 m 的超标量流水线时，相当于把 n 条指令分成「n 除以 m 向上取整」组，T = [ k + (「n/m 向上取整」 - 1) ] × Δt。

## 五、异常与中断

20.异常和中断的完整分类，见本章思维导图。

21.故障在可恢复的情况下（比如缺页），会重新执行当前指令；在不可恢复的情况下（比如非法指令、除零），会中止当前进程。

22.自陷一般执行它的下一条指令。

23.故障和自陷属于软件中断；中止和外中断属于硬件中断。

24.异常是内中断，中断是外中断。

25.异常由 CPU 执行指令过程中的错误引起，具有确定性和可重复性；中断由外部设备（IO控制器）发起，是异步事件，与当前指令无关，具有随机性。
