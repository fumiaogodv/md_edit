# 总线 · 总文件

> 说明：本章原始笔记的「总线概述」部分只有提纲式标题和少量文字，具体内容以图片为主。

## 一、总线的分类

```
总线
├─ 按数据传输格式
│   ├─ 并行总线
│   └─ 串行总线
├─ 按总线功能
│   ├─ 片内总线
│   ├─ 系统总线
│   │   ├─ 单总线
│   │   ├─ 双总线
│   │   ├─ 三总线
│   │   └─ 四总线
│   └─ 通信总线
└─ 按时序控制方式
```

**串行总线与并行总线**
- 串行总线：发送四个 bit 数据是一个一个发送的，接收方也是一个一个接收的。
- 并行总线：四个可以一起发送，接收也是四个一起接收。
- 二者速度不一定谁比谁快。因为并行虽然一次传输的数据多，但不能把频率做得太高。
- 像键盘、鼠标这些设备不需要那么快的速度，用并行等于把性能浪费了。
- 这里引入「通道」，就可以解决单总线解决不了的问题（单总线效率低，因为同一时间只能有一个总线工作）。

## 二、总线周期与总线操作

**总线周期的四个阶段**
1.申请阶段（也叫仲裁阶段）：需要用总线传输数据的模块对系统仲裁进行申请，然后得到使用权。
2.寻址阶段：得到使用权的模块发出需要数据的地址和操作的指令。
3.传输阶段：模块与它需要进行信息交互的设备进行数据传输，可以是单向也可以是双向。
4.结束阶段：传输结束后，相关权限和信息从总线上消失，等于没有存在过，同时让出总线使用权。

## 三、四种通信方式对比

| 通信方式 | 核心特点 |
|---|---|
| 同步通信 | 要求从设备也是高速设备，能跟上 CPU 高频率；要求总线长度较短，因为不做数据校验，总线越长数据越容易出错 |
| 半同步通信 | 总线传输周期不固定，会根据接收方接受的时间长短同步变化；能满足两个频率差异大的设备相互通信 |
| 异步通信 | 能满足两个频率相差大的设备交换信息；灵活可变；但速度慢一点，控制方式复杂一点 |
| 分离式通信 | 一个传输周期中只有主模块发请求、从模块回请求两个操作占用总线，准备数据时不使用总线，把这部分时间空出来以提高利用率 |

**分离式通信的两个前提**
1.从模块也要有权力申请占用总线（别的通信方式中从模块没有这个权力）。
2.同步通信，不需要等待对方回复。

## 四、三种异步定时方式（握手方式）

| 方式 | 请求信号 | 回复信号 |
|---|---|---|
| 不互锁 | 不管是否有回应都撤销 | 不管是否被接受都撤销 |
| 半互锁 | 要等收到回复信号才停止 | 不需要等对方接收就撤销 |
| 全互锁 | 要等接收到回复信号才撤销 | 要等请求信号撤销之后才撤销 |

## 五、突发传输与串并行

**突发传输与非突发传输**
- 突发传输：访问连续的数据，只需要第一次访问地址。
- 非突发传输：访问连续数据，每一次访问都需要给出地址。
- 例子：一个 32B 的内存块，一次只能访问 8B，突发传输只要 5 次（一次地址加四次数据），非突发传输要 8 次。

**同步异步与串并行**
- 同步串行：速度快，但需要额外的硬件开销。
- 异步串行：速度慢，只能传送简单的数据，结构简单。
- 并行传输：适合短距离、低频率的设备。
- PCIe 的十六条线也还是串行传输的设备；并行设备只有早期的 PCI 和内存总线。

## 六、性能指标

1.总线带宽，指的是能达到的最大频率；有效数据传输率，是指一段数据删去校验位、删去开头结尾等信息之后剩下的有效信息。
2.信号线数，就是三个总线数量的总和，单位是传输一个比特数据的一根线。
3.总线周期和总线时钟周期的关系有三种：多对一、一对一、一对多。
4.对于一些只需要很慢频率的 USB 外设，需要桥接器来发出更低频率的信号，送到 IO 总线等别的总线上。
