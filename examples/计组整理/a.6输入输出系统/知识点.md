# 输入输出系统 · 知识点

## 一、基本概念

1.通道的引入：更进一步减轻了 CPU 的任务，让通道去管就行，用于特别多的存储设备，比如百度云的机房。

2.统一编址：逻辑上 IO 地址和内存地址是一致的。独立编址：单独画出一个区域给 IO。

## 二、程序查询方式

3.程序查询方式对低频率的设备效果好；对高频率的设备，设备会一直独占 CPU，效果不好。

4.程序查询阶段没有 DMA 和中断处理，遇到慢速设备时 CPU 只能等。

## 三、中断相关的零散结论

5.当 CPU 收到了关中断的指令，它就不会再理会任何中断指令，直到下一次开中断。

6.原子操作：一旦开始就不能停止，一口气做完，所以需要配合关中断指令。在一些特别重要的数据更改中，要全部更改。

7.中断请求标记：用于判断这个中断信号是哪个设备发送的。

8.中断判优：经过一个数字电路，当输入多个1时，经过一系列变化，只有优先级最高的请求在输出端是1。

9.中断判优器：用于选择优先级最高的。

10.中断请求触发器：用于暂存中断信号。

11.当系统处理一个中断请求，就不再理会别的中断，这叫单重中断。

12.屏蔽字，就是有选择地选中那些重要的中断，不重要的中断就被屏蔽了。

13.屏蔽字原理：给当前的中断一个保护，如果你不想让那些中断打断它，就把对应中断的屏蔽触发器设为1。

14.中断优先级包括响应优先级和处理优先级。响应优先级由硬件决定，不可改变；处理优先级通过中断屏蔽字确定，是软件实现的。

15.关中断在中断服务程序前面，开中断在中断服务程序里面。

16.CPU 在系统态（内核态）下同样可以检测和响应中断。

17.外设准备数据的时间应大于中断处理时间，因为准备数据时 CPU 不用等待，准备时间越长说明数据越大，一次传送的性价比越高。

18.中断服务程序结束时，自动返回地址、结束中断，没有中断结束信号。

19.中断嵌套的时候，更高优先级的请求出现，也要等到当前某一条中断指令结束的时候才响应。

## 四、DMA 方式

20.DMA 控制器里有四样东西：数据寄存器、数据源地址、数据目的地址、计数器。

21.DMA 的工作流程：比如从磁盘向内存传递五个数据，先把源地址、目的地址和计数器都写好，然后每一个数据先通过数据寄存器，再到目的地址，这样工作。

22.DMA 控制器是用来处理块设备（以块为单位）的。

23.DMA 传输的最后一步，是向 CPU 发送一个中断信号，告诉它结束了。

24.对于正常的访问运行过程，CPU 就不能和主存通信了，因为总线被别的程序使用。而对于 DMA 来说，它有一条专用的 DMA 总线来访问主存，所以可以在传递数据的过程中还进行程序的运行。

25.虽然 DMA 和 CPU 都有一条总线和主存连接，但主存不能同时支持两个设备的读写，于是出现一些方式来提高效率。

26.DMA 和中断请求同时发生时，优先响应 DMA 请求。

27.DMA 传输请求在每一个机器周期结束就会发出；而 DMA 结束请求是在一个指令结束的时候发出。

28.周期挪用的情况下，DMA 收到一点数据，就会在一个机器周期结束时发送数据。

29.CPU 和 IO 接口中，主存的地址是不需要交换的。

## 五、设备与方式的匹配

30.有中断处理和 DMA 的情况：高速大吞吐量的设备给 DMA，慢速设备给 CPU 自己处理。
