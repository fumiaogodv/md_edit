# 进程调度

进程调度是操作系统核心功能之一，决定 CPU 在多个进程间如何分配时间。

## 调度算法

### 先来先服务（FCFS）

按进程到达顺序分配 CPU，简单但可能出现「饥饿」。

### 时间片轮转（RR）

每个进程分配固定时间片，轮流执行。

## 调度指标

| 指标 | 含义 |
|------|------|
| 周转时间 | 完成时间 - 到达时间 |
| 等待时间 | 周转时间 - 运行时间 |
| 响应时间 | 首次调度 - 到达时间 |

## 代码示例

```python
def fcfs(processes):
    """先来先服务调度"""
    processes.sort(key=lambda p: p.arrival)
    time = 0
    for p in processes:
        time += p.burst
    return time
```

## 数学公式

平均等待时间的计算：

$$
\bar{W} = \frac{1}{n} \sum_{i=1}^{n} W_i
$$

行内公式：$E = mc^2$。
