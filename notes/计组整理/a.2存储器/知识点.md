# 存储器 · 知识点

## 一、存储层次

1.存储器容量从大到小、速度从快到慢、价格从低到高，依次是：外存（磁带、光盘）、辅存（磁盘）、内存、高速缓冲寄存器（Cache）、寄存器。

2.两个搭配关系：主存与辅存的搭配，解决成本和容量的矛盾；Cache 与主存的搭配，解决主存与CPU速度不匹配的问题。

## 二、存储元与存储单元

3.信号线上面带一个横杠，说明这个信号是低电平生效。

4.一个存储体由多个存储单元组成，每一个存储单元又由多个存储元组成。

5.存储元一般四个或八个组成一个存储单元。

## 三、SRAM、DRAM、ROM 的零散结论

6.SRAM 发热量大。

7.SRAM 不需要考虑地址线复用，DRAM 需要考虑地址线复用。

8.DRAM 的刷新自动完成，不需要 CPU 控制。

9.DRAM 读写占一个时间周期，刷新占两个。

10.很多 ROM 也可以写。

11.很多 ROM 也支持随机存取。

12.主存包括内存和 BIOS，所以主存里既有 RAM 也有 ROM。其中内存用 DRAM，BIOS 用 ROM。

13.SRAM 用于 Cache，DRAM 用于内存，ROM 用于 BIOS。

14.MAR、MDR 都是 CPU 内部的寄存器。

## 四、容量与数据线

15.4M×8 的 DRAM，一个存储单元的大小是一字节。

16.单体多字存储器，单个存储单元的大小不为一字节。

17.地址线连接时，低位接地址，高位接译码器。

18.地址线1条、输出两条，叫 1-2 译码器；地址线3条、输出8条，叫 3-8 译码器。

19.MAR 的位数，取决于实际主存支持的空间大小，而不是现有 DRAM 的大小。这里的 MAR 相当于主板支持的最大内存，DRAM 相当于实际买的内存，只要不超出最大值都能装下。

20.位扩展之后，几块芯片在逻辑上相当于一块了，因为一个负责低位数据线，一个负责高位数据线，根本不能分开。

## 五、外部存储器

21.SSD 的写入机制：每次往一个块写字，比如写一个页，会先把这块里别的页全部移到一个新的块，然后在新块里对应的页写入，之后再改变逻辑地址与物理地址的映射算法，让它重新逻辑连续。

22.平均读取时间 = 巡道时间 + 旋转延迟时间 + 传输时间；更完整的写法是：平均读取时间 = 排队延迟 + 控制器时间 + 寻道时间 + 旋转等待时间（转一圈时间的一半）+ 数据传输时间。

23.传输时间有两种算法：一是转速除以扇区数；二是扇区数据大小除以传输速率。

######
24.**磁盘属于块设备，它的最小读写单位是“扇区（Sector）”**（通常为 512 字节或 4KB）
