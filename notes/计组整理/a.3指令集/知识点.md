# 指令系统 · 知识点

## 一、指令基本格式

1.除了零地址指令，别的地址码条数都是用算出的值再减一，因为要留出全一这个编码，当作0个操作码的代表。

2.一条指令由操作码 op 和地址码 A 组成。操作码告诉这条指令是干什么的，地址码决定在哪个数据上干这个事情。

3.由操作码可以确定地址码的数目。

4.根据每条指令的长度是否一致，分为定长指令和不定长指令。不定长的就是有些是半字长，有些是单字长等等。

5.根据每条指令操作码的长度是否一致，也分为定长和不定长。操作码定长时，操作码的种类数就和位数直接相关。


## 三、程序机器级代码表示

9.指令里的 IP 和 PC 意思一样，都是 program count，也就是指令指针。

10.eax、ebx 是 32 位；ax、bx 是 16 位；ah、al、bh、bl 是 8 位。

11.edx:eax 这种写法，指的是被除数原来是 32 位，但是要扩展到 64 位，所以用两个寄存器连起来使用。

12.ecx 一般用作计数器。

13.loop 的计数器只能用 ecx。

14.机器级代码指的是汇编代码。

15.偏移寻址中偏移量可以是负数就用补码表示
16.指令周期通常大于时钟周期
