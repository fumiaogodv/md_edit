## 一、顺序查找（Linear Search）
### 适用条件与结构
- 对表内关键字的有序性无要求
- 既支持顺序存储，也支持链式存储
### 时间复杂度
- 最好：$$O(1)$$
- 最坏 / 平均：$$O(n)$$
### 平均查找长度（ASL）
**成功**（等概率 $$P_i = \frac{1}{n}$$）：
$$
\text{ASL}_{\text{成功}} = \sum_{i=1}^n P_i \cdot i = \frac{n+1}{2}
$$
**失败**：
- 普通无序表：$$\text{ASL}_{\text{失败}} = n + 1$$（若带哨兵则比较 $$n+1$$ 次）
- 有序表的顺序查找（画判定树）：$$\text{ASL}_{\text{失败}} = \frac{n}{2} + \frac{n}{n+1}$$
### 高频考点与陷阱
1. **哨兵的作用**：在表头（下标0）设置待查关键字，从后往前查找，免去了每步检查“下标是否越界”的条件，提高检索效率。
2. **优化策略**：按访问频度排序（将常访问的放前面）。

## 二、折半查找（Binary Search / 二分查找）
### 适用条件
**必须是顺序存储，且关键字必须按序排列**（链式存储不能二分，因为无法 $$O(1)$$ 随机访问）。
### 时间复杂度
$$O(\log_2 n)$$
### 判定树（核心命题点）
- 折半查找的判定树是一棵**平衡的二叉排序树**
- 若内部结点（查找成功记录）有 $$n$$ 个，则外部叶子结点（查找失败）有 $$n+1$$ 个
- 树高 $$h = \lceil \log_2(n+1) \rceil$$（不计外部失败结点）
### ASL 计算
- **成功**：$$\text{ASL}_{\text{成功}} = \frac{1}{n} \sum (\text{各内部结点的层数})$$
- **失败**：$$\text{ASL}_{\text{失败}} = \frac{1}{n+1} \sum (\text{各失败结点的比较次数})$$，注意：失败结点的比较次数等于其父结点所在的层数。
### 高频考点与陷阱
1. 给定 `low`、`high` 和 `mid = (low + high) / 2`（向下取整或向上取整），要求**画出判定树**并计算 ASL。
2. 若向下取整，则右子树结点数 $$\ge$$ 左子树结点数；若向上取整则反之。

## 三、分块查找（Blocking / Index Sequential Search）
### 结构特点
**“块间有序，块内无序”**。包含主表和索引表，索引项包含“块的最大关键字”与“块的起始地址”。
### ASL 计算公式
$$
\text{ASL} = L_b (\text{索引表ASL}) + L_s (\text{块内ASL})
$$
若将长度为 $$n$$ 的表均匀分成 $$b$$ 块，每块 $$s$$ 个元素（$$n = b \times s$$）：
- **两部分均采用顺序查找**：
$$
\text{ASL} = \frac{b+1}{2} + \frac{s+1}{2} = \frac{s^2 + 2s + n}{2s}
$$
当 $$s = \sqrt{n}$$ 时，$$\text{ASL}$$ 取得最小值：$$\sqrt{n} + 1$$。
- **索引表折半，块内顺序查找**：
$$
\text{ASL} \approx \lceil \log_2(b+1) \rceil + \frac{s+1}{2}
$$
### 高频考点与陷阱
1. 索引表若用折半查找，当目标值不在索引表中时，折半查找停留在 `low > high` 处，**目标一定在 `low` 所指向的块中**（若 `low` 超出范围则失败）。
2. 块内必须用顺序查找（因为块内无序）。

## 四、二叉排序树（BST）
### 性质
左子树 $$<$$ 根 $$<$$ 右子树；**中序遍历序列严格单调递增**。
### 时间复杂度
- 最好（平衡状态）：$$O(\log_2 n)$$
- 最坏（单支树，退化为链表）：$$O(n)$$
### ASL 计算
- $$\text{ASL}_{\text{成功}} = \frac{1}{n} \sum (\text{各结点所在的深度})$$
- $$\text{ASL}_{\text{失败}} = \frac{1}{\text{失败结点总数}} \sum (\text{各失败结点父结点层数})$$
### 核心操作考点
1. **插入与构造**：给出一个输入序列，要求一步步画出二叉排序树的生成过程（输入顺序不同，树形不同）。
2. **删除结点（重点大题）**：
   - 删除叶子结点：直接删除。
   - 删除单分支结点：子树直接替代该结点。
   - 删除双分支结点：用其中序前驱（左子树最大值）或中序后继（右子树最小值）替代，然后转化为删除该前驱或后继。

## 五、平衡二叉树（AVL 树）
### 定义与性质
- 任意结点的平衡因子（$$BF = \text{左子树高} - \text{右子树高}$$）只能是 $$-1, 0, 1$$。
- 若高度为 $$h$$，最少结点数递推公式：$$N_0 = 0, N_1 = 1, N_2 = 2$$，通项为 **$$N_h = N_{h-1} + N_{h-2} + 1$$**（斐波那契变体，选择题极高频）。
### 时间复杂度
查找、插入、删除均为 $$O(\log_2 n)$$。
### 旋转调整（必考画图题）
- **LL（右单旋）**：在 A 的左孩子的左子树插入导致失衡，A 顺时针旋转下沉。
- **RR（左单旋）**：在 A 的右孩子的右子树插入导致失衡，A 逆时针旋转下沉。
- **LR（先左后右双旋）**：在 A 的左孩子的右子树插入，先对左孩子左旋，再对 A 右旋。
- **RL（先右后左双旋）**：在 A 的右孩子的左子树插入，先对右孩子右旋，再对 A 左旋。
> **速记口诀**：找出“最小不平衡子树”的三个关键结点，按中序遍历排序，中间的结点做新根，较小的做左孩子，较大的做右孩子。

## 六、红黑树（Red-Black Tree）
### 五大定义性质（口诀：左根右，根叶黑，不红红，黑路同）
1. 本质是二叉排序树。
2. 根结点是黑色。
3. 叶结点（外部虚拟 NULL 结点）均为黑色。
4. 红色结点的父子结点都不能是红色（无连续红结点）。
5. 从任一结点到其所有后代叶结点的路径上，包含相同数量的黑结点。
### 核心特性
- 从根到叶的最长路径不超过最短路径的 2 倍。
- 含 $$n$$ 个内部结点的红黑树高度 $$h \le 2\log_2(n+1)$$。
- 黑高为 $$h$$ 的红黑树，内部结点最少有 $$2^h - 1$$ 个。
- 查找/插入/删除时间复杂度：$$O(\log_2 n)$$。
### 插入调整规则（考选择题或简单填空）
- 新插入结点默认染为**红色**。
- 若叔叔结点（父结点的兄弟）为**红**：叔父爷变色，爷变红，向上传递检查。
- 若叔叔结点为**黑**（或 NULL）：旋转（LL/RR/LR/RL）+ 变色。

## 七、B 树与 B+ 树
### 1. $$m$$ 阶 B 树（多路平衡查找树）
#### 结点规格限制（必考）
- 根结点：若非空且非叶，子树数 $$2 \le k \le m$$，关键字数 $$1 \le n \le m-1$$。
- 其他分支结点：子树数 $$\lceil m/2 \rceil \le k \le m$$，关键字数 $$\lceil m/2 \rceil - 1 \le n \le m-1$$。
- 子树数始终等于关键字数 $$+ 1$$。
- 所有的叶结点（失败结点）都在同一层。
#### 树高与存取效率
$$n$$ 个关键字对应 $$n+1$$ 个叶结点；高度 $$h$$ 决定了磁盘 I/O 次数。
#### 核心操作考点
- **分裂（插入溢出）**：关键字数达到 $$m$$ 时，将第 $$\lceil m/2 \rceil$$ 个关键字上移至父结点，左右部分分别形成两个新子结点。
- **合并与借位（删除欠载）**：关键字数低于 $$\lceil m/2 \rceil - 1$$ 时，优先向左右兄弟“借”（需经父结点周转）；兄弟不够借时，与父结点的相应关键字及兄弟进行“合并”。
### 2. B+ 树 vs B 树异同（高频对比选择题）
| 比较维度 | $$m$$ 阶 B 树 | $$m$$ 阶 B+ 树 |
| --- | --- | --- |
| **关键字与子树关系** | 关键字数 = 子树数 $$- 1$$ | 关键字数 = 子树数 |
| **非根内部结点关键字范围** | $$\lceil m/2 \rceil - 1 \sim m - 1$$ | $$\lceil m/2 \rceil \sim m$$ |
| **信息存储位置** | 所有结点均包含记录数据 | **仅叶子结点**包含记录数据，分支结点仅做索引 |
| **叶结点链接** | 各叶结点互不相连 | 所有叶结点按关键字顺序**链成单链表** |
| **查找方式** | 仅支持多路树形查找 | 支持**随机查找**和沿叶子链表的**顺序查找** |

## 八、散列表（Hash Table）
### 核心指标
- **装填因子**：$$\alpha = \frac{\text{表中记录数 } n}{\text{散列表长度 } m}$$。$$\alpha$$ 越大，冲突概率越大，ASL 越大。
- **查找时间复杂度**：平均 $$O(1)$$，最坏（全部冲突退化）$$O(n)$$。
### 散列函数构造方法
- **除留余数法**：$$H(\text{key}) = \text{key} \pmod p$$，$$p$$ 取 $$\le m$$ 的最大质数。
- 直接定址法、数字分析法、平方取中法。
### 冲突处理方法与增量序列 $$d_i$$
1. **线性探测法**：$$d_i = 0, 1, 2, \dots, m-1$$。缺点：易产生聚集（堆积）现象。
2. **平方探测法（二次探测）**：$$d_i = 0^2, 1^2, -1^2, 2^2, -2^2, \dots$$。优点：避免聚集；缺点：不能探测所有空间，但至少能探测一半单元。
3. **伪随机探测法**、**双散列法**（$$H_i = (H(\text{key}) + i \times \text{Hash}_2(\text{key})) \pmod m$$）。
4. **拉链法（链地址法）**：同义词链成一个单链表，无同义词与非同义词的聚集。
### ASL 计算（必考大题）
**$$\text{ASL}_{\text{成功}}$$**：
$$
\text{ASL}_{\text{成功}} = \frac{\sum (\text{每个已有关键字在表中找到所需的比较次数})}{\text{关键字总个数 } n}
$$
**$$\text{ASL}_{\text{失败}}$$（最容易错的扣分点）**：
- **开放定址法**：查找直到遇到**空单元**才算失败。
$$
\text{ASL}_{\text{失败}} = \frac{\sum_{i=0}^{p-1} (\text{从地址 } i \text{ 开始探测到第一个空单元的比较次数})}{p}
$$
> 注：分母通常是散列函数取模数 $$p$$（即等概率落入 $$0 \sim p-1$$ 各个初始散列槽）。
- **拉链法**：
$$
\text{ASL}_{\text{失败}} = \frac{\sum (\text{各散列槽链表非空结点的比较次数，空链表比较0次})}{\text{散列槽位数 } p}
$$
### 陷阱提示
开放定址法删除结点时不能真正置空，必须做**删除标记**，否则会导致后续同义词查找提前截断造成“找不到”。
