## 4.对于将中缀表达式变成后缀表达式：
### 方法二：计算机栈算法（代码实现原理）
在计算机算法中，只需要**一个用于暂存运算符的栈**和一个输出队列（或直接按顺序输出字符）。
#### 优先级设定
- `*`、`/` 优先级高于 `+`、`-`。
- 栈外的 `(` 优先级最高（必须无条件压栈），但一旦**进了栈内，( 的优先级最低**（只有遇到 `)` 才能把它弹出来）。
#### 扫描规则（从左向右依次扫描中缀表达式的每个字符）
1. **如果是操作数（数字 / 字母）**：
   - **直接输出**到后缀表达式中。
2. **如果是左括号 (**：
   - **直接压入符号栈**。
3. **如果是右括号 )**：
   - 不断将栈顶运算符弹出并输出，**直到遇到左括号 ( 为止**。
   - 最后把这个 `(` 弹出丢弃（括号本身绝不输出到后缀表达式中）。
4. **如果是普通运算符（+、-、\*、/）**：
   - 依次比较当前运算符与栈顶运算符的优先级：
     - **若当前运算符优先级 $\le$ 栈顶运算符优先级**：栈顶运算符出栈并输出（因为栈里的高级运算必须先完成），然后将当前运算符放入栈   注意栈顶是最新输入的元素，不是最开始的元素
     - **直到当前运算符优先级 $>$ 栈顶运算符（或栈空、栈顶为 (）**，然后把当前运算符**压入栈中**。
5. **扫描完毕**：
   - 将栈中剩余的所有运算符依次弹出并输出。

运算优先级表：

| 读入字符 | 符号栈状态（栈底 $\to$ 栈顶） | 后缀输出序列 | 动作与说明 |
| --- | --- | --- | --- |
| **`A`** | `[空]` | `A` | 操作数直接输出 |
| **`+`** | `+` | `A` | 栈空，`+` 入栈 |
| **`B`** | `+` | `A B` | 操作数直接输出 |
| **`>`** | `>` | `A B +` | 当前 `>` 优先级低于栈顶 `+`，**`+` 出栈并输出**；随后 `>` 入栈 |
| **`C`** | `>` | `A B + C` | 操作数直接输出 |
| **`&&`** | `&&` | `A B + C >` | 当前 `&&` 优先级低于栈顶 `>`，**`>` 出栈并输出**；随后 `&&` 入栈 |
| **`!`** | `&& !` | `A B + C >` | `!` 优先级高于 `&&`，**`!` 入栈** |
| **`D`** | `&& !` | `A B + C > D` | 操作数直接输出 |
| **结束** | `[空]` | **`A B + C > D ! &&`** | 依次弹出栈顶：先弹 `!`，再弹 `&&` |

## 6.链队所有单指针方案终极排序
如果严格限制**只能持有一个指针**来做队列，从好到差的排序是：
1. **带尾指针的循环单链表（王者）**：
* 尾插（入队）$O(1)$，头删（出队，直接找 `rear->next`）$O(1)$。
2. **带头指针的循环单链表（平庸）**：
* 头删 $O(1)$，尾插 $O(n)$，但至少有环状特性，合并或遍历具有全域可达性。
3. **带头指针的非循环单链表（最差）**：
* 头删 $O(1)$，尾插 $O(n)$，单向死胡同无法回溯，本质上是“拿着链栈的结构硬装队列”。
4. **带尾指针的非循环单链表（无法工作）**：
* 尾插虽然是 $O(1)$，但出队根本找不到头节点，直接不可用。
