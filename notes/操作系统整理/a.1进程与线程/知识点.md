# 进程与线程 · 知识点

## 一、进程的概念与状态

1.进程是动态的、不断变化的；进程实体是静态的，类似于进程某一个瞬间的快照。

2.从运行态到阻塞态是主动停止。主动的含义：进程只有获得资源才可以继续，所以它主动选择阻塞来等待，这种没资源、被停止叫主动。被动指的是：程序还在正常运行，一个优先级高的程序要运行，系统给它停止了，这种有资源却不能运行叫被动。

## 二、进程控制

3.进程进行状态切换要做两件事：一是身份的改变（state 改变），二是物理指针的改变（让新队列指向它，它自己也指向别的 PCB）。如果做了一半就被中断，就会造成诸多混乱。

4.实现原子操作的逻辑：把希望不被打断的程序放在关中断和开中断之间。

5.关中断和开中断是特权指令，用户程序不能使用。

6.创建一个新进程需要用到原语。

7.作业调度指的是把程序从外存放入内存。

8.运行环境：把进程运行的一些数据先保存到 PCB 里，方便下一次再转为运行态的时候，从中断的指令处无缝衔接。

## 三、进程通信

9.进程通信的前提：各个进程不能随意访问别的进程的数据，否则安全性会出问题。

10.解决办法：划一片公共区域，通过映射让另一个进程访问特定数据；因为不能两个进程同时写，所以要加上 PV 锁。

11.共享存储区有两种结构：基于数据结构的共享、基于存储区的共享。

12.管道是半双工通信，只能单向传输；数据结构类似循环队列；允许多个写进程、一个读进程。

## 四、信号机制

13.信号的接收方不知道发送者是谁。

14.进程之间能发送的信号有限制，而内核发送的信号没限制。

15.进程处理信号的时机：从内核态转用户态的时候，也就是运行了 trap 或 IO 操作之后，统一检查一次。

16.判断哪些信号要处理：需要一个阻塞信号表和一个待处理信号表；待处理信号与「阻塞信号取反」做与运算，结果为 1 的信号就执行。

17.处理信号：为每一个信号都写一个处理程序，发生时自动执行；用户可以自定义，但 kill -9 这类核心信号不能自定义。

## 五、线程

18.用户级线程由进程自己的线程库管理，CPU 不需要变态，内核意识不到线程的存在，只认为它是一个进程。

19.用户级线程的缺点：一个线程阻塞整个程序就不能运行（并发性差），也不能在多核 CPU 上并行执行（并行性差）。

20.内核级线程的管理由操作系统内核完成，切换必须在核心态下进行；内核会为每个内核级线程建立 TCB。

21.TCB 和进程的 PCB 基本一样，放一些存储的数据信息，以便在中止后再次运行。

22.不支持内核级线程的操作系统：进程既是资源分配的基本单位，也是调度的基本单位；支持内核级线程的操作系统：进程是资源分配的基本单位，线程是调度的基本单位。

## 六、处理机调度

23.调度器决定了调度算法，以及每一个进程的运行时间。

24.触发调度程序的事件有四个：创建新进程、进程退出、运行进程阻塞、IO 中断发生。

25.时间片轮转算法：规定一个时间片，按时间片让程序执行，用完就回到队列排队；在此基础上再考虑到达时间不同的情况。

26.非抢占式优先级调度：每个程序运行完，再看是否有更高优先级的进程存在，存在就让它运行。

27.抢占式优先级调度：在每一个进程到达的时候，检查自己是否是高优先级的进程。

28.多级反馈队列调度：有多个队列，低优先级队列的时间片小；进程运行完会跑到下一级等待；只有低优先级队列为空，才可以运行高优先级的，被抢占的进程在原地等着。

29.响应比 = （等待时间 + 运行时间）÷ 运行时间。

30.部署进程上下文的是中断向量。

31.采用时间片轮转算法，当运行态的进程用完一个时间片后的状态是就绪态。

32.进程在临界区可以进行处理机调度，在内核临界区不可以。

## 七、同步与互斥

33.临界区指的是代码程序，临界资源指的是内存数据等。

34.互斥指的是同一时间只有一个进程访问临界资源；同步指的是一个资源能被特定顺序先后访问。

35.互斥信号量初值为一，同步信号量初值为 0 或 N。

36.共享程序段就是可重入代码段。

37.管程的 signal 只是唤醒操作，没有计数等功能；wait 操作也是立即阻塞，没有什么减一，那些功能要程序员自己通过 if 函数实现。

38.如果有 n 个进程，就绪队列最多 n-1 个，阻塞队列最多 n 个。

39.互斥机制允许让权等待。
